# 🏥 Hospital Patient Classification Dashboard

An AI-powered web application that classifies patients as **Normal** or **Abnormal** using anomaly detection techniques.
Built with Streamlit, this dashboard provides real-time data visualization and supports custom dataset uploads.

---

## 🚀 Features

* 📂 Upload your own CSV dataset
* 📊 Interactive data visualization (boxplots & charts)
* 🤖 Machine Learning model using Isolation Forest
* 🧠 Classifies patients as Normal / Abnormal
* 📈 Adjustable outlier percentage (sidebar control)
* ⬇️ Download classified results
* ⚡ Fast and user-friendly dashboard UI

---

## 🛠️ Tech Stack

* **Frontend/UI:** Streamlit
* **Language:** Python
* **Libraries:**

  * Pandas
  * NumPy
  * Seaborn
  * Matplotlib
  * Scikit-learn

---

## 📊 Dataset

* Default: Heart Disease Dataset (UCI)
* Users can upload their own medical dataset in CSV format

---

## ⚙️ How to Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/shameee09/Hospital-patient-classification.git
   ```

2. Navigate to the folder:

   ```bash
   cd Hospital-patient-classification
   ```

3. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

4. Run the app:

   ```bash
   streamlit run app.py
   ```
